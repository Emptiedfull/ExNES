# EXNES

Welcome to **ExNES**, a Nintendo Entertainment System emulator running using WASM. Use this page for getting started.

## Starting

The console starts off. To boot it up:

1. Press the **power button** (the ⏻ button on the console deck). 
2. Use the **navigation arrows**
  to browse through the available games.
3. Click the **selected cartridge** to slot it in.

## Controls

ExNES maps the NES controller to your keyboard by default. 

| Button       | Keyboard Key |
| ----------       | ------------ |
| A                | `Z`          |
| B                | `X`          |
| Select           | `Left Shift` |
| Start            | `Enter`      |
|  Up         | `Arrow Up`   |
|  Down       | `Arrow Down` |
| Left       | `Arrow Left` |
| Right.     | `Arrow Right`|

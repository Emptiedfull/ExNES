# Features

This page is a comphrensive list of all available features (hopefully)

## Power button

Controls the physical state of being **powered**. It also is the start of the console. Turning it on and off stimulates a power cycle. 

## Reset 

Works like the reset button on the physical NES. Only works in audio clocked mode.

## Play/Pause

Can be used to control the state of emulation. The pausing action is not instant and may cause 5-10 frames of lag. Only works in audio clocked mode.

## Rewind 

You found the easter egg WOHOOO , press R on the keyboard to bring up a selection of frames from the last 5 seconds. The frames are not in order btw. You can select a snapshot to load a point in time to rewind the emulator. 

## Timing Mode switch 

Check out [here](./docs/Timing.md)

## Fullscreen

Click on the television to enter fullscreen mode, resolution might be affected due to scaling artifacts. 

## Speed Control

Use the dial on the television to control the speed of emulation, it progresses in 50% increments. This is only supported in audio clocked mode. 

## Voluem control

Control volume using the on television dial, putting the dial on 0 will mute the game audio entirely but it will remain audio clocked.
